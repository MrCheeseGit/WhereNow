# Changelog

## 0.1.0

Initial release of **Where Now**: Server Connect step for current local date/time in a dynamic IANA timezone (DST-safe). Outputs `localDate`, `localTime`, `hour`, `minute`, and `dayOfWeek` for open-hours filtering.

See [README](README.md) for features, installation, and usage.
